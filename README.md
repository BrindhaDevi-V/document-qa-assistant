# Document Q&A Assistant

A Python project to explore document question answering using Retrieval-Augmented Generation (RAG).

## Planned Features

- Extract text from PDF documents
- Clean and split text into chunks
- Generate text embeddings
- Retrieve relevant document sections
- Generate answers using an LLM
- Evaluate answers and handle missing information

## Current Status

### Implemented
- PDF text extraction using pypdf
- Page-by-page extraction with page markers
- Validation for missing files and invalid extensions
- Error handling when no extractable text is found
- Automated tests using pytest

### Planned
- Text cleaning and preprocessing
- Text chunking
- Text embeddings
- Semantic retrieval
- LLM-based answer generation
- Answer evaluation and handling missing information
